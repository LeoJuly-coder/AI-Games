# 象棋翻翻棋 - Q版风格

一款2DQ版风格的象棋翻翻棋游戏，使用HTML+CSS+JavaScript实现。

## 游戏简介

象棋翻翻棋是一种趣味性强、运气与策略并重的象棋变体玩法，核心在于"暗棋翻面"与"大吃小"规则。

## 快速上手

### 棋盘棋子
- 使用半张象棋棋盘（4行×8列 = 32格）
- 32枚棋子打乱后背面朝上摆满棋格

### 阵营确定
- 先手玩家翻第一枚棋
- 翻到什么颜色即执该方（红或黑）
- 另一方自动归属另一色

### 行动方式
- 每回合可选择翻一枚暗棋或移动一枚明棋，二者选其一

## 核心规则

### 棋子大小
| 大小顺序 | 棋子 | 说明 |
| :--- | :--- | :--- |
| 1 | 将/帅 | 最大（被卒吃） |
| 2 | 士 | 第二大 |
| 3 | 象 | 第三大 |
| 4 | 车 | 第四大 |
| 5 | 马 | 第五大 |
| 6 | 炮 | 第六大 |
| 7 | 卒 | 最小（可吃将） |

### 走子限制
- 明棋每次只能移动一格（横或竖），不能走斜线
- 炮吃子需隔一枚棋子（炮架）

### 吃子规则
- 大子吃小子（同级棋子相遇同归于尽）
- 炮可隔子吃暗棋或明棋
- 特殊规则：卒可吃将

## 胜负判定
- 吃光对方所有棋子即获胜
- 无法移动时判负

## 游戏特色
- Q版可爱风格的棋子设计
- 流畅的翻棋动画效果
- 清晰的游戏状态提示
- 支持双人本地对战
