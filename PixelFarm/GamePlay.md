请创建一个符合复古像素风格和半调图案风格的贪吃蛇游戏，使用HTML+CSS+JavaScript实现。游戏设计应具备以下功能和视觉要求：

# 核心玩法：
- 通过键盘的方向键（上、下、左、右）控制人物的移动。
- 可以种植不同等级的水果，水果从种子到发芽到幼苗到成熟，每个阶段需要进行浇水才能继续发展。
- 不同等级的水果成长的时间不同，等级越高成长越慢。
- 施肥可以提升50%的速度。
- 游戏区域内会随机生成树木、岩石等障碍物，障碍物不会与任何其他元素重叠。
- 收获果实后，将果实保存到仓库中，仓库可以显示当前保存的果实数量，并且人物会获得经验值。

# 视觉设计风格：
- 整体风格： 游戏16bit像素风格，俯视视角‌（也称‌Top-down 视角‌），具体为‌斜45度角的2D像素风格俯视角‌。
- 人物： 人物由像素方块组成，能够移动并与环境互动。
- 植物： 植物呈现像素风图形，采用鲜艳的颜色并通过半调图案展现其变化。
- 背景： 游戏背景使用像（深蓝到靛蓝渐变），并在背景上加入柔和的像素网格（30px x 30px格子）作为装饰。
- 分数显示： 分数显示在右上角，使用像素字体，背景带有透明度和模糊效果，且得分更新时会有简单的动画效果。

# UI 设计要求：
- 游戏区域： 棋盘格地面深浅交替的草地，64x64格子地图，地图上需要有障碍物比如石头、树木、杂草之类的。
- 操作说明： 游戏底部提供简洁的操作说明，字体使用像素化设计，例如“使用方向键控制”。
- 游戏标题： 游戏顶部显示“像素农场”标题，使用复古像素字体并加入脉冲动画。
- 游戏结束： 游戏结束时，显示一个全屏半透明遮罩，包含“游戏结束”文字（使用渐变色和像素风格），以及重新开始按钮，按钮会在悬停时产生缩放效果。

# 互动效果：
- 人物交互时资源：资源会有震动效果，增强反馈感。
- 键盘控制反馈： 键盘方向键控制时，人物会有轻微的移动速度变化，增加游戏的流畅感。

# 技术要求：
- 游戏画面无滚动条，适配各种屏幕尺寸（响应式设计）。
- 使用 HTML5 CSS 和 JavaScript 实现，确保支持现代浏览器，优化性能。
- 支持触摸屏控制（移动端支持）。

# 色彩方案：
- 背景色： 绿色深浅交替，保持复古像素风格的沉稳色调。
- UI元素色： 按钮、标题、分数等UI元素应使用鲜明对比的颜色，例如白色、亮蓝色、明黄色等。

# 代码要求：
- HTML结构： 使用语义化的HTML结构，清晰定义游戏区域、分数、控制按钮等元素。
- CSS样式：
  - 游戏区域： 使用CSS Grid布局，将地图分为64x64个格子。
  - 人物： 人物由像素方块组成，使用CSS伪元素实现。
  - 植物： 植物呈现像素风图形，使用CSS背景图实现。
  - 背景： 游戏背景使用CSS渐变实现。
  - 分数显示： 分数显示在右上角，使用CSS字体和透明度实现。
  - 操作说明： 操作说明在底部，使用CSS字体和透明度实现。
  - 游戏标题： 游戏标题在顶部，使用CSS字体和脉冲动画实现。
  - 游戏结束： 游戏结束时，使用CSS遮罩和按钮实现。
- JavaScript逻辑： 通过 JavaScript 进行游戏逻辑的控制，包括人物的移动、资源的生成、数据计算等。
